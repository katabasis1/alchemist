## Ждём от пользователя (S2.2)
1. Распаковать **`outbox/alchemist_update_gh-9888a1e_to_v0.1.2.zip`** поверх проекта (если в архиве есть `DELETED.txt` — удалить перечисленные файлы). Картинок в этом подэтапе нет.
2. Открыть в Godot 4.7 (он создаст `*.uid` для новых скриптов и шейдеров), закоммитить и запушить.
3. `scenes/debug/grind_check.tscn` → **F6**, пару секунд не трогать → ждём `GRIND: 31/31 OK`, ниже — памятка для ручной проверки (круги и свайпы, шкала, тапы, уход пальца, корзина). Заодно `shelf_check.tscn` → `SHELF: 30/30 OK` (ступка поменялась). Прислать Output, если есть ошибки или FAIL.
4. Главное на ощупь: скорость помола (`circle_length_px` = 520 px пути на круг, `grind_*` в `data/economy/economy_config.tres`) — не слишком ли быстро/медленно.
