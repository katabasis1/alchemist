## Ждём от пользователя (M0)
1. Создать пустой репозиторий на GitHub и выгрузить проект из `archive/alchemist_repo.bundle` (инструкция — `README.md`, раздел «Первая выгрузка на GitHub»).
2. Открыть проект в Godot 4.7: должна открыться лавка с клиенткой за прилавком, в панели Output — без ошибок. Если ошибки есть — прислать текст.
3. Закоммитить созданные Godot файлы `*.import` и `*.uid`, запушить, положить ZIP репозитория (GitHub → Code → Download ZIP) в `inbox/` Pod.
4. (к S1.7) Шрифты OFL с кириллицей в `inbox/fonts/` — кандидаты в ART_STYLE.md §5. Если не пришлют — агент подберёт сам из свободных.
