## Ждём от пользователя (S2.1)
1. Распаковать **`outbox/alchemist_update_gh-df4d87b_to_v0.1.1.zip`** поверх проекта и **удалить файлы из `DELETED.txt`** внутри архива (лишние файлы S2.0 и копия проекта в `tools/`). Новые картинки этого подэтапа лежат в архиве — их тоже скопировать.
2. Открыть в Godot 4.7 (он создаст `*.uid`/`*.import` для новых файлов), закоммитить и запушить.
3. `scenes/debug/shelf_check.tscn` → **F6** → ждём `SHELF: 30/30 OK`, ниже — памятка для ручной проверки (перенос, отскок, тап, корзина, лента в узком окне). Прислать Output, если есть ошибки или FAIL. Предупреждения SaveService «запись до загрузки пропущена» в этой сцене — норма.
4. По желанию: финальная графика по промптам P-PROP-01…04, P-UI-06, P-UI-07 → `inbox/art/` под теми же именами.
