Все числа — **стартовые значения** (Numbers Policy): проверяются плейтестом, итог фиксируется в `docs/GDD.md`.

## Версии
- `v0.0.1` — первый коммит на GitHub: минимальный проект, который открывается в Godot 4.7.
- Далее: каждый завершённый подэтап = `+0.0.1`; каждая контрольная точка = `+0.1.0` (M1 → 0.1.0, M2 → 0.2.0, M3 → 0.3.0, M4 → 0.4.0); релиз в Яндекс Играх = `1.0.0`.
- Снапшоты: `archive/history/alchemist_v<версия>_<ID>_<slug>.zip`.

## Сквозные правила (действуют на ВСЕХ этапах)
1. **GitHub с v0.0.1.** Обмен с репозиторием — через Pod (у Computer нет интернета): протокол в `AGENTS.md` §2.
2. **Графика: временная + промпт сразу.** Любой новый графический элемент: агент генерирует временную версию → вырезает фон → кладёт в проект по контракту → **в тот же подэтап** пишет готовый промпт для ChatGPT Image в `docs/art/PROMPTS.md` и строку в `docs/art/ASSET_REGISTRY.md` (статус `temp`). Пользователь генерирует финальную версию когда удобно → `final`.
3. **Тексты: очеловечивание.** Любой текст, который видит игрок (ru и en), до попадания в `localization/strings.csv` проходит humanizer: ru — `tools/humanizer/ru/SKILL.md` (+ `check_facts.py`), en — `tools/humanizer/en/SKILL.md`. Ключ вносится в `localization/humanized.txt`. Валидатор ругается на ключи без отметки.
4. **Проверка без Godot:** валидатор `tools/validate_project.py` после каждого подэтапа; пользователь открывает проект в Godot на контрольных точках.
