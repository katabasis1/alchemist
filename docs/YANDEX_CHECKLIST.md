# YANDEX_CHECKLIST — требования Яндекс Игр, важные для нашего проекта

Источник: https://yandex.ru/dev/games/doc/ru/concepts/requirements (сверено 2026-10-24). Перед отправкой — перепроверить актуальную версию.

## Техника
- [ ] 1.1 SDK подключён, есть «готовность» (LoadingAPI.ready) в момент, когда игра готова к игре.
- [ ] 1.3 При потере фокуса звук останавливается (и игра на паузе).
- [ ] 1.4 / 1.13 Платежи только через SDK; при покупках — консумирование, валюта из SDK, прогресс на сервере.
- [ ] 1.6.1 Мобильные: полный экран, управление жестами, лонгтап не выделяет и не открывает меню, нет уведомления о WebGL.
- [ ] 1.6.2 ПК: поле растягивается до края, длинная сторона ≤ 2× короткой, управление мышью/клавиатурой без зависимости от раскладки, нет выделения/контекстного меню.
- [ ] 1.8 Интерактивные элементы удобного размера.
- [ ] 1.9 Прогресс сохраняется сразу после действия игрока; после обновления страницы прогресс на месте.
- [ ] 1.10 Корректное отображение при ресайзе и повороте: ничего не обрезается и не накладывается, нет браузерного скролла, игра управляется одной рукой, основной экран без прокрутки.
- [ ] 1.11 Если облачные сохранения — включить опцию в черновике.
- [ ] 1.12 Подключена монетизация (реклама или покупки).
- [ ] 1.21 Размер распакованной игры ≤ 100 МБ (наша цель гораздо меньше — см. S11.1).
- [ ] 1.23 Нет интерактивного ИИ; заранее сгенерированный ИИ-контент (графика) допустим.

## Геймплей
- [ ] 2.9 Контента минимум на 10 минут (цель MVP — 1–2 часа).
- [ ] 2.13 Рейтинг > 30 в первые 3 недели, иначе снятие из каталога.
- [ ] 2.14 Язык определяется автоматически через SDK.

## Контент (0+/6+)
- [ ] 3.4.2 Никакой «чёрной магии»: черепа, пентаграммы, демоны, проклятия, некромантия.
- [ ] 3.4.3 Никакой жестокости к животным: тесты на существах — мультяшные, безболезненные, смешные.
- [ ] 3.4.5 Никакой религиозной символики.
- [ ] Никаких реальных веществ/лекарств и медицинских советов — только сказочные свойства.

## Реклама
- [ ] Реклама только через SDK.
- [ ] Interstitial — после действия игрока, в логических паузах (между заказами), не во время мини-игры.
- [ ] Rewarded — добровольно, кнопка явно помечена как реклама с наградой, награда выдаётся.
- [ ] На время рекламы — пауза игры и звука (GameplayAPI stop/start).

## Промо и тексты
- [ ] Название уникальное, без слова «игра»; иконка — не скриншот; скриншоты в основном геймплей; описание и «Как играть».
- [ ] Тексты без ошибок, не обрезаются, переведены (ru обязательно, en — желательно).
- [ ] Консоль браузера без ошибок.
