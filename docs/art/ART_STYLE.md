# ART_STYLE — стиль A «Уютный сказочный мультяшный»

Статус: **v1.0 — утверждён** (2026-10-24). Стиль A выбрал пользователь; по пробникам и макету правок не было, команда дала «продолжи». Правки стиля по-прежнему возможны: финальная графика встаёт на место временной под тем же именем и размером.
Референсы: `docs/art/reference/style_A_mockup.jpg` (макет экрана), `docs/art/reference/style_A_assets_sheet.png` (вырезанные ассеты).

## 1. Суть стиля
- Ручная «рисованная» мультяшная графика для казуальной игры: **уверенный тёплый тёмно-коричневый контур** средней толщины, мягкая cel-тень с лёгкой живописной фактурой.
- Пропорции **пухлые и дружелюбные**, силуэты читаются на телефоне.
- Свет: **тёплый ключевой сверху слева**, мягкий контровой свет по краю.
- Ракурс предметов: **3/4 спереди, чуть сверху**. Фон лавки — фронтальный вид.
- Настроение: уют, любопытство, «светлое» волшебство. **Нельзя:** черепа, кости, пентаграммы, оккультные/религиозные символы, демоны, тёмная мрачная гамма (требования Яндекса 3.4.2, 3.4.5).

## 3. Правило «пустых объектов» (D6)
ИИ рисует только **статичные пустые** предметы в нейтральных цветах: пустые колбы, ступку без порошка, мебель, персонажей, UI.
Шейдеры и частицы в Godot рисуют: жидкости и их слои, порошок, цвет свойств, пузыри, пар, свечение, искры, блики-«прокатки».
Стекло всегда **прозрачное** (фон виден сквозь стекло), чтобы под ним шла жидкость-шейдер.

## 4. Технические правила
- **Временная графика (агент):** генерация на сплошном фоне `#FF00FF` (для розового/фиолетового/персонажей — `#00FF00`) → `python tools/art/cutout.py` (режим `flood` для непрозрачных, `global` для стекла; `--split` для листов) → PNG по контракту.
- **Финальная графика (пользователь, ChatGPT Image):** промпты в `docs/art/PROMPTS.md`. Генерировать в **одном чате** ChatGPT, приложив оба референса из `docs/art/reference/`. Просить прозрачный PNG; если нет — сплошной `#FF00FF`/`#00FF00`.
- **Сдача финала:** файл с именем из `ASSET_REGISTRY.md` → `inbox/art/` в Pod (или сразу в репозиторий). Агент вырезает фон/вписывает в холст тем же `cutout.py` и заменяет временный файл **под тем же именем и размером**.
- **Холсты** (при базовом разрешении 1920×1080): фон 1920×1080; предметы 512×512 / 384×512; ингредиенты и иконки 256×256; клиенты 768×768 (низ обрезан по груди — стоят за прилавком).
- **Имена:** `bg_*`, `prop_*`, `ing_*`, `client_<кто>_<эмоция>`, `ui_*`, `icon_*`; только латиница, `snake_case`.
- ChatGPT отдаёт 1024×1024 / 1536×1024 / 1024×1536: для фона — 1536×1024, важное в центральной полосе 16:9 (верх/низ ~8% обрежутся).

## 5. Открытые вопросы
- Портретная раскладка (телефон): нужен отдельный фон `bg_workshop_portrait` — создаётся на S1.2.
- Шрифты (OFL, с кириллицей): кандидаты — заголовки `Kurale` / `Neucha`, текст `Nunito` / `Rubik`. Computer без интернета → файлы шрифтов положит пользователь в `inbox/fonts/` (S1.2).
