# Лавка алхимика

Уютный 2D-симулятор алхимической лавки для **Яндекс Игр** (рабочее название).
Godot **4.7**, GDScript, рендерер **Compatibility**, web-экспорт однопоточный. Стиль A — уютный сказочный мультяшный.

Текущая версия — в `project.godot` (`config/version`), статус работ — в [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Как открыть
1. Godot 4.7 → **Импорт** → выбрать `project.godot`.
2. При первом открытии Godot создаст папку `.godot/` (она в `.gitignore`) и файлы `*.import` / `*.uid` рядом с ассетами и скриптами. **Их нужно закоммитить**: на них держатся стабильные ссылки `uid://`.
3. F5 — запуск. Пока на экране лавка, клиентка за прилавком и сам прилавок. Вертикальная раскладка появится на S1.5, до этого в портретном окне сверху и снизу будут коричневые поля.

## Структура
| Папка | Что внутри |
|---|---|
| `scenes/` | Сцены `.tscn`. Каждый объект игры — отдельная сцена из узлов-компонентов |
| `assets/` | Графика по контракту `docs/art/ASSET_REGISTRY.md` (имя и размер холста фиксированы) |
| `audio/` | Раскладка аудиошин, позже звуки |
| `docs/` | План, прогресс, журнал, GDD, стиль, промпты для ChatGPT Image (Godot эту папку не видит) |
| `tools/` | Валидатор, вырезка фона, humanizer, синхронизация с Pod (Godot эту папку не видит) |

## Первая выгрузка на GitHub (один раз)
1. На GitHub создай **пустой** репозиторий: без README, `.gitignore` и лицензии, иначе будет конфликт историй.
2. Скачай из Pod файл `archive/alchemist_repo.bundle` (это весь git-репозиторий с историей и тегами).
3. В терминале:
   ```
   git clone alchemist_repo.bundle alchemist
   cd alchemist
   git remote set-url origin https://github.com/<логин>/<репозиторий>.git
   git push -u origin main --tags
   ```
   История и хеши коммитов совпадут с моими, поэтому следующие обновления из bundle подтянутся обычным `git pull`.

Без терминала можно так: распаковать `archive/alchemist_latest.zip` и загрузить файлы через веб-интерфейс GitHub. История агента при этом теряется, поэтому после такой загрузки положи ZIP репозитория в `inbox/` Pod, и я синхронизируюсь с ним.

## Дальнейший обмен
**От агента к тебе** — после каждого подэтапа в Pod обновляются `archive/alchemist_repo.bundle`, `archive/alchemist_latest.zip`, `outbox/patches/v<версия>/` и `archive/LAST_SYNC.txt` (какая версия и какой коммит выгружены). Забрать изменения можно одним из способов:
1. **Через bundle (рекомендую, история и теги совпадают с моими):** скачай свежий `alchemist_repo.bundle` и в папке репозитория выполни
   ```
   git pull --no-rebase путь/к/alchemist_repo.bundle main
   git fetch --tags путь/к/alchemist_repo.bundle
   git push
   git push --tags
   ```
2. **Через патчи:** `git am путь/к/outbox/patches/v<версия>/*.patch`, потом `git push`. Теги так не переносятся, а хеши коммитов будут другими, но содержимое то же.
3. **Целиком:** распаковать `archive/alchemist_latest.zip` поверх рабочей копии (чистое дерево без `.git`).

**От тебя к агенту** — после того как открывал проект в Godot или что-то менял:
- GitHub → **Code → Download ZIP** → положить в `inbox/` Pod;
- финальные картинки от ChatGPT Image → `inbox/art/` с **теми же именами**, что в `docs/art/ASSET_REGISTRY.md`.

## Проверка без Godot
```
python tools/validate_project.py            # сцены, ресурсы, скрипты, локализация, ассеты
python tools/validate_project.py --self-test
```
Нужен только Python 3.10+, пакеты не нужны.

## Правила разработки
Коротко: композиция вместо наследования, все объекты — сцены и узлы, данные — в `.tres`, тексты — через ключи локализации и humanizer, графика — временная плюс сразу промпт для ChatGPT Image. Полностью — в [`AGENTS.md`](AGENTS.md).
