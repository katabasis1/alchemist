# Лавка алхимика

Уютный 2D-симулятор алхимической лавки для **Яндекс Игр** (рабочее название).
Godot **4.7**, GDScript, рендерер **Compatibility**, web-экспорт однопоточный. Стиль A — уютный сказочный мультяшный.

Текущая версия — в `project.godot` (`config/version`), статус работ — в [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Как открыть
1. Godot 4.7 → **Импорт** → выбрать `project.godot`.
2. При первом открытии Godot создаст папку `.godot/` (она в `.gitignore`) и файлы `*.import` / `*.uid` рядом с ассетами и скриптами. **Их нужно закоммитить**: на них держатся стабильные ссылки `uid://`.
3. F5 — запуск. Пока на экране лавка, клиентка за прилавком и сам прилавок. Вертикальная раскладка появится на S1.5, до этого в портретном окне сверху и снизу будут коричневые поля.

## Структура
| Папка | Что внутри |
|---|---|
| `autoload/` | Глобальные сервисы (автозагрузки сценами): `EventBus`, `Platform` (+ mock), `GameState`, `SaveService`, `AudioDirector`, `SceneRouter` |
| `scenes/` | Сцены `.tscn`. Каждый объект игры — отдельная сцена из узлов-компонентов. `scenes/debug/` — проверочные сцены |
| `assets/` | Графика по контракту `docs/art/ASSET_REGISTRY.md` (имя и размер холста фиксированы) |
| `audio/` | Раскладка аудиошин, позже звуки |
| `docs/` | План, прогресс, журнал, GDD, стиль, промпты для ChatGPT Image (Godot эту папку не видит) |
| `tools/` | Валидатор, вырезка фона, humanizer, синхронизация с Pod (Godot эту папку не видит) |

## Дальнейший обмен
Источник правды — твой репозиторий на GitHub (ветка `main`). Его история не совпадает с историей агента, поэтому bundle для `git pull` больше не подходит: изменения приходят **файлами или патчами**.

**От агента к тебе** — после каждого подэтапа в Pod появляются:
- `outbox/alchemist_update_v<версия>.zip` — **только изменённые и новые файлы** с прошлой выдачи. Это основной способ:
  1. распакуй архив **поверх** папки проекта (с заменой файлов); если внутри есть `DELETED.txt` — удали перечисленные файлы;
  2. закоммить и запушь (или GitHub → **Add file → Upload files** → перетащи содержимое архива с папками → Commit).
  Картинок PNG/JPG в обновлениях нет, пока агент сам их не менял: твои файлы не затрутся.
- если ты пропустил несколько выдач — `outbox/alchemist_update_<твоя версия>_to_v<версия>.zip`: всё сразу одним архивом, ставится так же;
- `outbox/patches/v<версия>/*.patch` — то же самое патчами: в папке репозитория `git am путь/к/*.patch`, потом `git push`.

`archive/alchemist_latest.zip` и `project/` — полное текстовое зеркало для агентов: **без картинок**, распаковывать его вместо проекта нельзя.

**От тебя к агенту:**
- код и тексты агент читает с GitHub сам (`raw.githubusercontent.com`), ничего присылать не нужно — просто запушь;
- картинки (финальные от ChatGPT Image и любые другие бинарные файлы) агент с GitHub скачать не может → `inbox/art/` Pod с **теми же именами**, что в `docs/art/ASSET_REGISTRY.md`.

## Проверка в Godot
Проверочные сцены лежат в `scenes/debug/`: открой сцену и нажми **F6**, итог появится в Output.
- `services_smoke.tscn` — автозагрузки, ждём `SMOKE: 8/8 OK`;
- `components_demo.tscn` — компоненты, ждём `COMPONENTS: 20/20 OK`; ниже в Output — что проверить руками;
- `data_check.tscn` — данные игры (`data/catalog.tres`), ждём `DATA: 23/23 OK`;
- `l10n_check.tscn` — переводы ru/en, шрифты и тема, ждём `L10N: 9/9 OK`; на экране образцы текста, язык сам переключается каждые 2 секунды;
- `shelf_check.tscn` — полка ингредиентов и ступка, ждём `SHELF: 30/30 OK`; ниже в Output — что проверить руками;
- `grind_check.tscn` — помол в ступке (жест, шкала, тапы, пауза, корзина) и его отклик (крошки, пыль, распад, порошок, кольцо и лучи, светлячки, вибрация), идёт пару секунд, ждём `GRIND: 47/47 OK`; ниже — памятка.
- `order_check.tscn` — мини-заказ во всей лавке: оценка зелья, кто придёт, клиент и пузырь, баночка из ступки, отказы, оплата, полёт монет в счётчик, сброс игры; идёт секунд пятнадцать (экран не трогать), ждём `ORDER: 61/61 OK`; ниже — памятка. Сохранение здесь не грузится, строка SaveService «запись до загрузки пропущена» — так и задумано.

Язык игры: настройка игрока → язык платформы (в редакторе — язык ОС; для проверки английского задай `language_override = "en"` у узла `PlatformMock` в `autoload/platform/platform.tscn`).

## Правила разработки
Коротко: композиция вместо наследования, все объекты — сцены и узлы, данные — в `.tres`, тексты — через ключи локализации и humanizer, графика — временная плюс сразу промпт для ChatGPT Image. Полностью — в [`AGENTS.md`](AGENTS.md).
