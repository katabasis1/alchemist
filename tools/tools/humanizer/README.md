# Humanizer — офлайн-копии навыков очеловечивания текстов

Все тексты игры проходят очеловечивание перед попаданием в локализацию:
- **русский** — `ru/SKILL.md` (источник: https://github.com/Vladimir-Human/humanizer-ru, MIT);
  скрипты: `ru/scripts/check_facts.py` (сверка фактов до/после), `ru/scripts/clean_paste.py`;
- **английский** — `en/SKILL.md` (источник: https://github.com/blader/humanizer, MIT).

Копии сохранены 2026-10-24, потому что Computer работает без интернета.
Порядок применения к игровым текстам — см. AGENTS.md §3 п.6 и PLAN.md (подэтапы с текстами).
